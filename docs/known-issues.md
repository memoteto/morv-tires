# مشكلات معروفة غير محسومة

## فشل متقطع عند خروج عملية pytest في CI (مستقلة عن Phase 3، **غير محسومة**)
- **الأعراض:** في تشغيل CI رقم 43679270329 (PR #8، أول محاولة) انتهت خطوة `pytest (أدوات التطوير)` بالفشل رغم أن كل الاختبارات نجحت (145 نجحت، 0 فشلت): على Linux بانهيار `Segmentation fault` (رمز 139)، وعلى Windows برمز خروج 1 دون رسالة خطأ ظاهرة في السجل.
- **ما نعرفه:** الانهيار يقع بعد انتهاء الاختبارات وطباعة النتيجة. التعليق في `run_tests.py` يصف انهيار Qt عند تدمير الكائنات بالخروج على Linux، وهو التفسير المرجَّح لكنه **غير مثبت**، ولم يُفسَّر رمز Windows.
- **ما لا نعرفه:** السبب الجذري، ولا نسبة التكرار، ولا هل يسبق Phase 3 (الأرجح أن فرع Phase 3 لا يضيف Qt، لكن لم يُختبر).
- **الوضع:** أعيد تشغيل المهام الفاشلة فنجحت. **إعادة التشغيل ليست إصلاحًا**؛ المشكلة قائمة وتحتاج تشخيصًا مستقلًا (مثل تشغيل `pytest -p faulthandler` وتكرار التشغيل، أو إنهاء العملية كما يفعل `run_tests.py`). لم تُعدَّل قواعد CI ولا `os._exit` في هذه الدفعة.
