# قرارات اعتماد مخالفة للتصميم v1.0

مرجع التصميم المعتمد: `design/` (نسخة من 21 شاشة + `canvas.json`، تصميم v1.0 بتاريخ 2026-11-13).
هذا المستند يوثّق الانحرافات المعتمدة من المالك عن ذلك التصميم.

## 1. رقم فاتورة المورد اختياري

التصميم (`Purchase.dc.html`) يضع علامة `*` إلزامية على رقم فاتورة المورد.
القرار المعتمد: الحقل اختياري في التطبيق الفعلي، لأن بعض الموردين لا يصدرون فواتير مرقّمة.

## 2. إعادة استخدام `ItemDialog` بدل نافذة "إضافة صنف سريع"

التصميم يفترض نافذة مصغّرة لإضافة صنف سريع أثناء الشراء/البيع.
القرار المعتمد: استخدام نفس `ItemDialog` الكامل بدل بناء نافذة مصغّرة منفصلة، لتفادي ازدواج منطق التحقق وقواعد الحقول.

## 3. عمود "مقارنة بتكلفة آخر شراء" بدل "أسعار البيع / هامش الربح الأدنى"

التصميم (`Purchase.dc.html`) يعرض عمود أسعار بيع وحد أدنى للهامش عند الشراء.
القرار المعتمد: استبداله بعمود يقارن سعر الشراء الحالي بتكلفة آخر عملية شراء لنفس الصنف، لأن حساب هامش الربح يتطلب منطق تسعير غير مفعّل بعد.
